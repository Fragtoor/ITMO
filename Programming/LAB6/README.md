### Лабораторная работа №6: Клиент-серверное приложение
Программа представляет собой консольное клиент-серверное приложение для управления коллекцией объектов.
* **Функционал:** Клиент принимает команды пользователя с консоли, сериализует их и отправляет на сервер по сети. Сервер обрабатывает команды, выполняет операции над коллекцией в памяти (добавление, удаление, сортировка, фильтрация) и возвращает результат обратно клиенту.
* **Особенности:** Валидация пользовательского ввода на стороне клиента, корректная обработка разрывов сетевого соединения и автоматическое сохранение состояния коллекции при завершении работы.

> **Стек и технологии:** Java 17, Java Networking (Sockets, ServerSocket), Object Serialization, Maven, Docker, Linux (Helios server).
