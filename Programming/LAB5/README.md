### Лабораторная работа №5: Управление коллекцией в консольном режиме
Базовая версия приложения для управления коллекцией объектов через интерактивный консольный интерфейс.
* **Функционал:** Чтение команд из стандартного потока ввода, валидация пользовательских данных и выполнение операций над коллекцией (добавление, обновление по id, удаление, очистка, фильтрация). Поддерживается выполнение скриптов с командами из файла.
* **Особенности:** Данные коллекции загружаются из XML/JSON файла при старте и сохраняются обратно при завершении работы. Реализована обработка рекурсивных вызовов в скриптах и устойчивость к некорректному вводу пользователя.

> **Стек и технологии:** Java Core (Collections API, Stream API), File I/O, JSON/XML Parsing (Jackson / GSON / DOM), CLI, OOP Design Patterns (Command).
