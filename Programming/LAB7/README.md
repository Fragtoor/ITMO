### Лабораторная работа №7: Многопользовательская система с хранением в БД
Приложение эволюционирует в многопользовательский сервис с хранением данных в реляционной базе данных вместо текстового файла.
* **Функционал:** Появилась система регистрации и аутентификации. Каждая команда теперь выполняется от имени конкретного пользователя, а объекты коллекции строго привязаны к их создателю — редактировать или удалять чужие элементы нельзя.
* **Особенности:** Сервер умеет параллельно обрабатывать запросы от множества клиентов без блокировки всей системы. Поддерживаются ACID-транзакции в БД и безопасное хранение хэшей паролей.

> **Стек и технологии:** PostgreSQL, JDBC, Prepared Statements, Multithreading (`ExecutorService`, `ForkJoinPool`, `ReentrantLock`), Password Hashing (SHA-256).
