### Лабораторная работа №8: Графический клиент и визуализация
Приложение получает полноценный графический интерфейс (GUI) вместо консоли.
* **Функционал:** Пользователь просматривает коллекцию через интерактивную таблицу с сортировкой и фильтрацией по любому полю, а также управляет объектами через диалоговые окна.
* **Особенности:** Добавлена визуальная карта, где объекты отображаются графически (с привязкой к координатам). При клике на объект открывается окно редактирования, а изменение элементов в реальном времени сопровождается анимациями. Реализована динамическая смена языка интерфейса.

> **Стек и технологии:** JavaFX / Swing, Concurrent Collections, `ResourceBundle` (i18n / L10n), Canvas API, JavaFX Animations.
